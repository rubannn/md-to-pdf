# Рев’ю на статтю: **«ReuNify: A Step Towards Whole Program Analysis for React Native Android Apps»**

## ВСТУП

Стаття *«ReuNify: A Step Towards Whole Program Analysis for React Native Android Apps»* авторів Yonghui Liu, Xiao Chen, Pei Liu, John Grundy, Chunyang Chen та Li Li присвячена проблемі статичного аналізу застосунків, створених із використанням React Native. Основна дослідницька проблема полягає в тому, що сучасні інструменти аналізу Android-додатків не враховують специфіку взаємодії між JavaScript та нативним кодом, що призводить до неповного покриття програмного коду.

Метою дослідження є розробка підходу, який дозволяє виконувати повний (whole-program) статичний аналіз React Native Android-додатків. Для цього автори пропонують інструмент ReuNify, який інтегрує JavaScript і Java-код в єдине проміжне представлення (Jimple), що може бути оброблене фреймворком Soot.

## МЕТОДОЛОГІЯ

Методологія дослідження базується на розробці прототипу інструменту ReuNify та його експериментальній оцінці на реальних застосунках. Основний підхід складається з двох ключових етапів:

1. **Генерація Jimple-коду** – трансформація як Dalvik байткоду (Java), так і Hermes bytecode (JavaScript) у спільне проміжне представлення. Для цього використовуються інструменти Dexpler, hermesc та hbcdump (описано на схемі сторінки 4).
2. **Виявлення міжмовних викликів** – аналіз зв’язків між JavaScript і Java кодом за допомогою pointer analysis, що дозволяє відновити приховані виклики між середовищами.

Дослідження включає емпіричну оцінку на 14~874 популярних Android-додатках та понад 60~000 зразків malware. Для аналізу використовувався інструмент FlowDroid, який виконує taint analysis для виявлення витоків даних.

## РЕЗУЛЬТАТИ

Результати дослідження демонструють значний вплив ReuNify на якість статичного аналізу:

- Збільшення кількості Jimple-коду приблизно на *70%*, що свідчить про суттєве покращення покриття аналізу.
- Зростання кількості вузлів у call graph в середньому на *84% для популярних застосунків*.
- Виявлення додаткових викликів між JavaScript і Java, які раніше не враховувалися.
- У середньому знаходиться *на 2 більше витоків приватних даних* у кожному застосунку при використанні ReuNify.

## КЛЮЧОВІ ІНСАЙТИ

### 1. Важливість міжмовного аналізу
Ігнорування взаємодії між JavaScript і нативним кодом призводить до значної втрати інформації. Це важливо, оскільки в сучасних кросплатформених застосунках логіка часто розподілена між кількома мовами, підкреслює необхідність врахування повного стеку технологій при аналізі або тестуванні програм.

### 2. Використання єдиного проміжного представлення
Ідея об’єднання різних мов у спільне IR (Jimple) є дуже ефективною. Вона дозволяє застосовувати існуючі інструменти без необхідності створення нових аналізаторів. Наведений підхід можна застосувати для інших мульти-мовних систем, що значно спрощує аналіз.

### 3. Недооцінка прихованого коду
Стаття показує, що значна частина виконуваного коду взагалі не аналізується традиційними методами, навіть перевірені інструменти можуть пропускати критичні вразливості.

## ВИСНОВОК

Стаття робить вагомий внесок у галузь статичного аналізу мобільних застосунків, пропонуючи новий підхід до аналізу React Native Android-додатків. ReuNify демонструє, що інтеграція різних мов програмування в єдине представлення значно підвищує точність і повноту аналізу.

Основні внески роботи:
- розробка нового підходу до whole-program analysis,
- покращення покриття статичного аналізу,
- виявлення додаткових вразливостей.

Загалом, робота є важливою для розвитку інструментів аналізу сучасних кросплатформених застосунків і має значний практичний потенціал.
